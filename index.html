Cool Stuff You Can Do in HTML

HTML is the skeleton of a website, CSS makes it look awesome, and JavaScript makes it move, react, calculate, and become a real app or game.

🏗️ Build Web Pages

Create home pages, about pages, portfolios, blogs, sports pages, and project galleries.

<h1>My Website</h1>
<p>I built this with HTML.</p>

🎨 Design Anything

Use CSS for gradients, glowing cards, animations, shadows, layouts, glass effects, and responsive phone-friendly pages.

.card{
  border-radius:20px;
  background:linear-gradient(blue,purple);
}

🎮 Make Games

With JavaScript and canvas, websites can become games like Snake, Pong, Breakout, Flappy Bird, platformers, and clicker games.

const canvas = document.querySelector('canvas');
const ctx = canvas.getContext('2d');

🧠 Make Smart Tools

You can make calculators, quizzes, flashcards, timers, score trackers, habit trackers, and homework helpers.

button.onclick = function(){
  score = score + 1;
}

📸 Add Media

HTML can show images, audio, videos, icons, GIFs, embedded maps, and YouTube videos.

<img src="photo.jpg" alt="cool photo">
<video controls></video>

📱 Make It Work on Phones

Responsive design lets your website look good on computers, tablets, and phones.

@media(max-width:800px){
  .grid{grid-template-columns:1fr;}
}
